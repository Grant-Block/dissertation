# dissertation
Codes and models used for the unpublished chapters of "Exploring the Role of Mushy, Compliant Crust in Volcano Deformation"

This repository includes analysis codes and model input files used in Chapters 2 and 5 of the dissertation. 

Chapter 2 makes up the bulk of the files included here, in addition to "dissertation_plots.py", which generated all of the plots in Chapter 2 (and two other Python scripts which it calls), the .timedb files, .exo mesh files (as well as all journal files used to generate the trelis meshes), and .cfg files used as inputs for all models are included. I do not include the model output files here, as they are too large, but they can be regenerated by running PyLith with the corresponding input files (all files and directories are named by run number). I can also send the model outputs by email, if they are needed, please email me at gblock@unm.edu. Also, inside the "codes" directory, there is a file named "run_list.csv" which stores the directory of all the model output files, and is called by the plotting code. When new output files are generated, update their directory in run_list.csv so they can be seen and called by dissertation_plots.py.

The main component here used in Chapter 5 is the file "codes/terzaghi_plots.py". This solve the analytic PVE solution, as well as plots it for different values of viscosity, shear modluls, etc... Also included are different lookup tables for PVE solutions for pressure, displacement, and trace strain. The solutions take time to generate, so lookup tables are generated first and then used to make the plots in Chapter 5. The code can generate new lookup tables, or the included ones can be used to replicate the plots.
